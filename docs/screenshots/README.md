# Screenshots

Drop screenshot files into this folder with the exact names below. They are
referenced from the top-level `README.md` and from this file.

Recommended format: PNG, aspect ratio ~16:9, width ~1600 px. Keep file size
under ~500 KB each; use an image optimiser if needed.

## Tips

- Use a browser window of 1600×900 or similar.
- Make sure no real sensitive information is visible (real passwords, real
  external IPs, real Wi-Fi passwords, real home addresses). Blur or replace
  with demo data.
- For the "Choose a home" screenshot, create two demo homes — one with a
  generic placeholder photo, one without a photo — so both states are shown.
- For mobile screenshots, a physical device or DevTools device emulation
  works fine.
